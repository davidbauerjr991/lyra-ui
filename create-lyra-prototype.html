Install Lyra UI?

Lyra UI is the design system your prototype will be built from. Nothing installs on your computer — your choice here is written into the prompt this wizard generates at the end, and Claude does the actual download when you paste it. Choose "Already Installed" only if Claude set up Lyra UI earlier in the same chat you'll paste into.

Clicking either button may also ask for read access to your work folder (pick the folder that contains your Prototypes and lyra-ui folders) so this wizard can list your prototypes and components. It only asks once — press Esc to skip.

What would you like to do?

Pick how you want to build — everything stays no-terminal, no installs.

Duplicate a Repo

Claude recreates the repo's UI exactly — same screens, layout, and flows — as a single html prototype built on the latest Lyra UI components.

Pick a folder on your computer, or paste any public GitHub repository URL.

My Components

Your custom components live in your own lyra-ui copy (src/components/local/) — never touched by library updates, never pushed without your say-so. Submit has Claude validate a component against the library rulebook and package it for the library owner to review.

Your components

First refresh asks you to pick your lyra-ui folder once (a browser security requirement) — after that it's remembered and refreshes silently. View opens the component in your browser; Edit opens it and gives you a prompt to start a Claude Cowork chat pointed at that component. Delete generates a prompt too — files aren't removed until you paste it.

This gallery will show your own Lyra UI components once you create some. It rebuilds automatically whenever Claude adds or changes one.

Browsing the standard library? Use the live Lyra UI Storybook ↗

To create your first component:
  1. In a Claude Cowork chat, describe what you need — e.g. "create a status pill component that shows call sentiment".
  2. Claude builds it into your lyra-ui's src/components/local/ folder (it persists on your machine).
  3. Ask Claude to rebuild this gallery — or use the wizard's My Components step.
